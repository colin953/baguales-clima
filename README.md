# Baguales Clima

App web instalable con las estaciones meteorológicas de Baguales (La Mesada y Antena; estaciones bajas próximamente).

- Los datos vienen de la planilla "Baguales Weather Station Data" a través de su Google Apps Script (`?data=1`).
- Para instalarla en el teléfono: Android, menú de Chrome → Instalar app; iPhone, Safari → Compartir → Agregar a inicio.
- Al cambiar archivos de la app, subir `VERSION` en `sw.js` para que los teléfonos tomen la versión nueva.
